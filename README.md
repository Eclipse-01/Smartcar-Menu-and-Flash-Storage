# 嵌入式菜单系统 (Embedded Menu System)

一个功能强大、高度可定制的嵌入式设备菜单系统。它包含一个可视化菜单配置生成器，让您无需编写复杂的结构体代码，通过拖拽和点击即可轻松创建、配置和管理多级菜单。菜单项支持修改 int 或 float 类型参数、进入子菜单、以及在菜单中直接调用函数。该项目深度集成了数据持久化、命令行调试等高级功能，旨在为基于逐飞科技 (Seekfree) HAL库的开发提供一套完整、高效的参数调节与人机交互解决方案。在CYT2BL3上经过验证。

## ✨ 主要特性 (Features)

- **💻 可视化配置**: 提供 `菜单配置.html` 图形化工具，彻底简化菜单的设计流程。
- **📚 多级菜单**: 支持无限层级的嵌套子菜单，轻松构建复杂逻辑。
- **🔧 多样的项目类型**: 内置对整数、浮点数、布尔值、执行函数和子菜单的支持。
- **💾 持久化存储**: 集成了一个独立的键值 (Key-Value) 存储系统，可以将任意配置（包括菜单数据）可靠地保存到 Flash 中。
- **🎨 自定义主题**: 在可视化配置器中轻松调整菜单的配色方案和布局。
- **🕹️ 硬件交互**: 原生支持编码器和独立按键输入，用于菜单导航和参数修改。
- **🔌 命令行接口 (CLI)**: 提供一个通过 UART 的命令行接口，用于在线调试和管理键值存储，极大地方便了开发过程。

## 🎯 目标平台与硬件 (Target Platform & Hardware)

本菜单系统基于逐飞科技 (Seekfree) 开源的 HAL 库进行开发和优化，完美适配其 IPS200 (2.0寸) 显示屏。

- **显示**: 所有图形绘制函数均针对 IPS200 屏幕的驱动和分辨率进行了优化。
- **输入**: 核心交互逻辑专为编码器 (旋转) 和独立按键设计，旨在提供最流畅、直观的参数调节和菜单导航体验。

## 🛠️ 如何在我的项目中使用 (Integration Guide)

### 环境依赖 (Prerequisites)

- 确保您的项目工程是基于逐飞科技的HAL库建立的。
- 确保您的硬件已连接 IPS200 屏幕、一个编码器以及逐飞的主板。

### 复制代码 (Copy Files)

将整个 `project/code/Menu/` 文件夹完整地复制到您自己项目的源码目录下，并在IDE中添加到工程。

### 配置硬件输入 (Configure HID)

这是最关键的一步。打开 `Menu/HID.c` 文件。根据您自己的电路原理图，修改文件顶部的引脚定义和文件底部的硬件读取函数，使其能够正确地读取到您的编码器和按键的电平状态。

### 初始化与调用 (Initialization & Invocation)

在您的 `main.c` 文件中，参照以下结构完成初始化和调用：

```c
#include "zf_common_headfile.h"
#include "Configurator_Headfile.h" // 包含菜单系统的核心头文件

int main(void)
{
    clock_init(SYSTEM_CLOCK_160M); // 1. 系统时钟初始化
    debug_init();                  // 2. 调试串口初始化

    // --- 集成菜单系统 ---
    ips200_init(IPS200_TYPE_SPI);  // 3. 屏幕初始化
    kv_storage_init();             // 4. 键值存储系统初始化
    kv_storage_format();           // 注意，首次使用此项目必须格式化存储，这是由于逐飞库在读取空区域时设备会崩溃的一个Bug造成的。只要运行过一次，你就需要把这里注释掉了
    InitializeAllMenus();          // 5. 初始化所有菜单结构 (从 Menu_Content.c)
    // --------------------

    // ... 此处可以添加其他用户外设的初始化代码 ...

    // 进入菜单系统主循环
    // 注意: EnterMenu 是一个阻塞函数，它将接管程序循环。
    // 只有当用户从最顶层菜单退出时，才会执行下方的代码。
    EnterMenu(&MainMenu);

    // 用户从菜单退出后，程序会继续执行到这里
    ips200_clear();
    ips200_show_string(20, 120, "Menu has been exited.");

    for(;;)
    {
        // 主循环，用于执行非菜单状态下的任务
        // 例如：在这里运行小车的主逻辑
    }
}
```

#### 关键点说明

- `kv_load_data()` 函数会在 `EnterMenu()` 内部自动调用，无需在外部手动执行。
- `EnterMenu()` 函数包含了自身的 `while(1)` 循环。程序会停留在该函数内部，直到用户从根菜单按“返回”键退出。
- 首次使用前，请务必调用 `kv_storage_format()` 函数进行格式化。这是由于逐飞库在读取空区域时设备会崩溃的一个Bug造成的。只要运行过一次，你就需要把这里注释掉了。  

### 开始设计 (Start Designing)

完成以上步骤后，您的项目就已经成功集成了菜单系统。现在，来到 [快速上手] 部分，使用 `菜单配置.html` 工具来设计您自己的菜单，生成代码并替换到项目中，然后编译烧录即可看到效果。

## 🚀 快速上手 (Getting Started)

我们强烈推荐使用可视化配置器来开始您的项目，这是最简单、最高效的方式。

1. **打开配置器**: 在您的电脑浏览器中打开 `菜单配置.html` 文件。
2. **设计菜单结构**: 使用“添加新菜单”按钮创建根菜单和子菜单。在每个菜单中，点击 + 按钮添加所需的菜单项（如整数、函数调用等）。为每个菜单项配置其名称、类型、默认值以及其他特定属性。
3. **自定义外观**: 在“主题与全局设置”区域，您可以调整颜色、每页最大项目数等参数。
4. **生成代码**: 点击 “生成并下载C代码” 按钮。浏览器将下载一个 ZIP 压缩包，其中包含两个核心文件：
    - `Menu_Content.c`: 根据您的设计自动生成的菜单结构定义。
    - `Configurator_Headfile.h`: 包含主题和全局配置的头文件。
5. **集成到项目中**: 将解压后的这两个文件覆盖到您项目中的 `project/code/Menu/` 目录下。
6. **编译和烧录**: 重新编译您的项目并将其烧录到目标设备上。

现在，您设计的菜单已经可以在设备上运行了！

## 🗄️ 独立的键值存储系统 (Standalone KV Storage)

本项目包含一个强大且独立的键值(Key-Value)存储系统，它允许您将程序的配置参数（如整数、浮点数）以“键”和“值”的形式保存在Flash中，实现数据的持久化存储。菜单系统本身就是使用此工具来保存用户设置的。您可以将此模块轻松剥离，用于任何需要数据持久化的 C 语言项目。

### C API 接口

在您的代码中包含 `KV_Storage.h` 后，即可调用以下函数来操作KV存储：

```c
void kv_storage_init(void);           // 初始化KV存储系统，应在程序启动时调用一次。
void kv_load_data(void);              // 从Flash加载所有键值对到内存缓存中。
void kv_save_data(void);              // 将内存缓存中的所有键值对保存到Flash中。
bool kv_storage_set_int(const char *key, int value);      // 设置一个整数类型的键值对。
bool kv_storage_set_float(const char *key, float value);  // 设置一个浮点数类型的键值对。
bool kv_storage_get_int(const char *key, int *value);     // 根据键获取一个整数值。
bool kv_storage_get_float(const char *key, float *value); // 根据键获取一个浮点数值。
bool kv_storage_remove(const char *key);                  // 根据键删除一个键值对。
bool kv_storage_format(void);                             // 格式化整个Flash存储区域，此操作会清除所有数据，请谨慎使用。在首次使用时必须调用。
```

## 命令行调试工具 (CLI)

为了方便调试和管理存储在Flash中的数据，系统还提供了一个通过UART的命令行接口(CLI)。

- **启动方法**: 在您的代码中调用 `kv_cli()` 函数即可进入CLI模式。
- **功能**: 您可以通过串口终端连接到设备，并使用以下命令来管理键值存储：

| 命令           | 功能                       |
| -------------- | -------------------------- |
| list           | 显示所有的键值对           |
| find [key]     | 查找指定的键               |
| delete [key]   | 删除指定的键值对           |
| set [key] [value] | 设置一个键值对 (自动检测类型) |
| format         | 格式化Flash存储            |
| save           | 将数据保存到Flash          |
| load           | 从Flash加载数据            |
| help           | 显示帮助信息               |
| exit           | 退出CLI                    |

```text
            ├── HID.c/h                 # 处理硬件输入（编码器和按钮）

            ├── UserConfig.h            # 用户自定义配置文件

            ├── Menu_Content.c          # (由此工具生成) 定义菜单的结构和内容

```

## 🔧 在我的项目中单独使用KV存储系统

如果您只需要使用键值存储系统而不需要菜单功能，可以单独集成 KV 存储系统。只需将 `KV_Storage.c` 和 `KV_Storage.h` 文件复制到您的项目中，并在代码中调用相关函数即可。但是请注意，你不能单独使用菜单系统的其他部分，因为它依赖于键值存储来保存用户设置和菜单状态。
